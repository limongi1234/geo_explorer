# Fluxo Git

- Commits pequenos, em português, no padrão Conventional Commits: `feat:`, `fix:`, `test:`, `docs:`, `refactor:`, `chore:`.
- Uma branch por funcionalidade (`feat/cards`, `feat/mcp`), integrada à `main` por pull request.
- Antes de commitar: testes passando e nenhum arquivo de `target/` ou `output/*.md` incluído.
